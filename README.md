# Canadian Retail Sales Analytics

## Project Overview
Built an end-to-end retail analytics solution using Statistics Canada retail sales data, Python, and Power BI.
## Dashboard Preview

![Canadian Retail Sales Analytics Dashboard](dashboard-original.png)

## Pipeline
Statistics Canada → Python download → unzip → clean → statistical analysis → CSV → Power BI refresh

## Python Analysis
- Month-over-Month Growth
- Year-over-Year Growth
- 3-Month Moving Average
- 12-Month Moving Average
- 3-Month Volatility
- Z-Score Analysis
- Anomaly Detection

## Power BI Dashboard
Includes:
- Total Sales
- Average Monthly Sales
- Latest MoM Growth %
- Latest YoY Growth %
- Latest 3M Volatility %
- Anomaly Months
- Sales trend analysis
- Growth trend analysis
- Anomaly detection
- YoY growth gauge
- Date filtering

Statistics Canada Monthly Retail Trade data.
